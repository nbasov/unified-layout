# unified-layout
Yet another English and Russian layouts for MacOS

## ANSI

* Line 1
  - def - `en` for both layouts
  - shf+ - `en shift` for both layouts
  - opt+ - `en opt` for both layouts
  - shf+opt - `ru shift` for RU layout
    
* Lines 2-4
  - opt+ - right edges symbols from US layout
  - shf+opt - right edges symbols from US layout
